# IP Pic 产品定义

## 产品目标

`ip-pic` 是一个可独立安装的开源 Agent Skill。它把文章、段落或静态视频关键帧的语义内容，转换为由用户自有或获授权固定角色参与核心认知动作的连续 IP 配图。

公开版以只读私有上游的 IP Skill 及其实际调用的共享 IP 核心、模板、脚本和回归测试为唯一行为事实源。公开版追求合同等价，不接受“功能相似”。

## 目标用户

- 需要为中文短文或长文生成固定角色正文配图的个人与团队。
- 需要生成 16:9、1:1、3:4、9:16 或自定义画布静态关键帧的内容团队。
- 需要角色连续性、逐图 QA、部分失败重做和整批重建的生产工作流。

## 必须提供

1. 文章 IP 配图与静态视频关键帧。
2. 原版内容导演：认知锚点、8 类结构、7 类镜头、人物尺度、动作、表情、视线、头部姿态、朝向、裁切、视觉锚点和批次轮换。
3. 原版 13 个正式结构模板，以及孤立兼容模板的显式映射。
4. 原版 6 个正交渲染风格；结构、身份、画布、文字策略和渲染风格互不偷换。
5. `direct-integrated`：一次生成必须包含少量、清晰、与动作和物件融合的画面文字。
6. `two-step-publish`：无字 raw 后确定性合成中文发布图，raw 永不冒充 final。
7. selection receipt、授权参考图选择、provider-neutral handoff、批量连续性、整批重建、逐图 QA、部分失败和失败重做。
8. Codex Image Tool、OpenAI Direct、宿主 ai-router、prompt-only 四条可配置渲染路径。
9. 中英文安装、配置、安全、扩展和使用文档。

## 允许的发行差异

仅允许以下差异：

1. 私人身份、姓名、外貌、服装、饰品、角色 bible、品牌锁定、参考图、私有路径和业务信息被删除或替换。默认教程角色为原创“学习向导阿拓”；悟空和月兔为额外教程角色。
2. 知识卡片、封面、海报、笔记系统、课程项目和发布平台能力被排除。
3. 私有 ai-router 的 provider、adapter、凭证、路由、余额、重试和 fallback 不公开；只有渲染边界替换为四条公开路径。
4. 增加独立安装所需的公开文档、安全门禁和发行元数据。

## 不做

- 不生成或分发 Ian 的“小黑”角色或示例图。
- 不复刻未授权第三方角色。
- 不制作动画、口型、配音、逐字字幕轨或视频剪辑。
- 不写入笔记系统、课程项目或内容发布平台。
- 不把结构测试包装成真实视觉通过。
- 未经单独确认不 push、tag、发布 GitHub Release 或安装 Global Skill。

## 成功证据

- parity manifest 对原版 IP 文件和共享依赖的映射覆盖率为 100%，零未映射项。
- 同一中性角色和内容在原版与公开版编译后，归一化身份、路径和后端字段，director plan、模板、prompt 文字策略、handoff、manifest 与 QA 合同等价。
- 自动化矩阵覆盖模板、风格、画布、文章长短文、静态关键帧、批量、参考图、部分失败、四后端路径和安全门禁。
- Codex Image Tool 真实 E2E 的 `direct-integrated` 结果含可读画面文字。
- 最终报告单独列出仍需用户人工判断的角色一致性、构图质量、风格辨识和中文字形质量。
