# 项目级角色、风格与导演配置验证报告

日期：2026-08-04  
候选版本：0.3.0-rc.3  
验证范围：独立版 IP Pic 的项目级自定义能力

## 结论

项目级角色、个人风格和导演预设已经具备可交付的自动化证据。普通用户可以直接告诉 Agent 自己想新增或修改的角色、服装、参考图、风格、表情、动作、视线和姿态；Agent 会先给出变更预览，得到确认后再写入当前项目的 `.ip-pic/`，并保留不可变历史版本和可回退的启用指针。

本轮没有修改原版私有 Image Factory，也没有把用户配置写入已安装 Skill。项目数据与公开 Skill 代码保持隔离。

## 小白用户—Agent 全流程复测

在一个临时空白项目中，以干净安装副本完成了以下流程：

1. 用户用自然语言要求新增已授权角色、个人风格和导演预设。
2. Agent 生成变更预览；未确认时不创建注册表、不写入配置。
3. 用户确认后，Agent 创建三个项目级配置并启用。
4. 使用项目角色、个人风格、表情、动作、视线和姿态编译 direct-integrated 图文融合任务。
5. 验证最终 prompt 使用用户动作，不再混入默认导演动作。
6. 新建角色第二版后，历史第一版仍可读取。
7. 将启用版本回退到第一版并重新编译，服装描述随版本正确切换。
8. prompt-only 路径返回可交给图片工具的请求，不伪装成已经出图。

黑盒复测曾发现“构图动作已更新，但视觉主体仍保留默认动作”的冲突。该问题已经用回归测试固定并修复；修复后全量测试重新通过。

## 安全与所有权边界

- 只接受用户明确声明已拥有或已获授权的本地参考图。
- 参考图必须位于当前项目内，且不得通过符号链接逃逸项目目录。
- 角色、风格、导演配置只写入当前项目 `.ip-pic/`。
- 每次修改创建新版本，不覆盖历史文件。
- 未确认、计划被篡改、注册表版本漂移或输入越界时均拒绝写入。
- 公开包不包含私人身份、私人角色素材、私有路径、凭证或私有路由实现。

## 仍需真人视觉验收

本报告证明的是结构、配置生命周期、编译、prompt、交付合同、安全门禁和确定性行为，不等同于真人审美验收。正式对外发布前或 Beta 使用过程中，仍建议使用真实图片后端重点查看：

- 自有角色在多图、不同动作和表情中的视觉一致性；
- direct-integrated 中文字体、手绘强调线和图文融合的美观度；
- 新增个人风格在真实图片中的辨识度与稳定性；
- 方屏、竖屏和长文章多图的整体连续性。

这些视觉项需要看真实生成图片判断，不能由字符串或 JSON 测试替代。
