# IP Pic Agent-first 用户手册设计

日期：2026-08-02
状态：已批准并按用户反馈收紧
适用版本：`0.3.0-rc.2`

## 1. 事实源

用户确认，正确的新手流程来自旧版公开手册，而不是当前命令密集型手册：

1. 用户把公开 Skill 地址交给 Codex、Claude Code、WorkBuddy 等 Agent。
2. 用户只说“帮我安装并使用这个配图工具，带我完成第一次配图”；其余安装与检查由 Agent 自动完成。
3. 用户只发送一条“使用阿拓示例给这段文字配 1 张图”的短提示词，不先选择模板、风格、比例、字体或图片工具。
4. Agent 内部自动选择可用出图方式，并在首次示例中自动生成“学习向导阿拓”参考图供用户看图确认。
5. 确认后 Agent 继续完成示例；用户之后只需把示例文字换成自己的短文或 Obsidian 文章。
6. 用户需要换自有角色、制作参考图、调试风格、新增个人风格、画布、文字模式或字体时，再进入对应的详细教程。

旧版流程只作为交互事实源；私有实现、旧后端、旧素材和过时能力数量不得恢复。

## 2. 文档分层

- `USER-GUIDE.zh-CN.md` / `USER-GUIDE.en.md`：只面向普通内容创作者，使用可直接复制给 Agent 的自然语言。
- `IMAGE-TOOL-SETUP.zh-CN.md` / `IMAGE-TOOL-SETUP.en.md`：仅在 Agent 明确报告没有可用图片工具时打开，保留真实后端和凭证边界。
- `MAINTAINER-GUIDE.zh-CN.md` / `MAINTAINER-GUIDE.en.md`：保留已有的命令、合同、测试、排错和扩展说明。
- `SKILL.md`：要求宿主 Agent 内部完成技术工作，只在权限、费用、角色权利和真实看图时暂停。
- `README.*`：30 秒产品入口，直接把用户路由到 Agent-first 手册。

普通用户手册只写内容创作动作和可直接发送给 Agent 的正向话术。版本号、安装位置、检查门禁和实现术语只存在于内部合同或维护者资料，不在用户入口解释“你不需要懂什么”。

出图配置不是普通用户每次运行示例前的必选步骤。主手册只说明 Agent 会自动优先使用可用的 GPT Image 2 工具；以下细节迁入按需打开的图片工具接入说明：

- Codex Image Tool 使用 GPT Image 2、由 Codex 管理且不需要用户配置 API Key；
- OpenAI 官方 API 的 `OPENAI_API_KEY` 放在宿主安全凭证入口或进程环境，固定使用官方地址；
- OpenAI 官方直连必须在有授权参考图时调用 Images Edit 并提交全部已选素材；请求身份绑定 model、quality、operation 与输入图哈希，返回图须匹配 PNG 与精确尺寸合同；
- 中转站的地址、Key 和模型属于宿主工具或 ai-router 的用户级配置，不属于 IP Pic；
- 已有 ai-router 只通过 `ai_router.generate_image` 接收上游交付，不暴露或修改 Router 内部；
- `prompt-only` 不是出图方式，必须明确显示尚未真实出图。

## 3. 首次参考图

公开包只分发“阿拓”的原创文字设定，不分发人物图片。第一次运行阿拓示例时，由宿主 Agent 在同一个任务中使用该设定生成教程参考图；用户不需要先发送一段单独的参考图工程提示词。只有用户明确确认后，才能将其用于后续连续性参考。重做必须新建版本，不覆盖旧图。

这一设计同时满足原始上手流程、公开发行隐私门禁和角色资产授权边界。

## 4. 原版行为约束

- 默认 direct-integrated 必须保留原版粗手写中文、重点强调和手绘线条的图文融合效果，不能退化为可选文字。
- two-step-publish 必须先生成无字图，再用确定性文字层加入标题。
- Agent 不得因为文档简化而改变 13 个结构、六种风格、导演计划、prompt、批量连续性、重试或逐图 QA。
- Obsidian 只是宿主 Agent 读取文章的入口，不扩展 `ip-pic` 的业务边界。

## 5. 验收

- 文档回归测试锁定安装 → 一条短提示词直接运行阿拓示例 → 自己的短文/Obsidian 长文 → 自有角色/参考图/风格定制的顺序。
- 普通用户手册和 README 不得出现版本号、安装位置、Python、JSON manifest、render handoff 或命令行参数。
- 安装段只保留一条交给 Agent 的自然语言话术；Agent 自动处理安装和检查。
- 首次示例提示词不得夹带图片工具检查、模板、比例、字体、后端或 QA 指令。
- 独立图片工具说明必须覆盖 Codex Image Tool、OpenAI 官方 API、中转站宿主管理和已有 ai-router，并说明凭证与服务地址的真实存放边界。
- 自有参考图、修改内置风格、新增个人风格与新版本保存必须在主手册中详细说明。
- 技术手册必须完整保留真实命令与四种后端说明。
- 由未参与编写的 Agent 模拟完全小白用户，逐步复述操作并报告阻断点。
- 自动化测试通过不代表视觉通过；字体、融合文字、人物连续性和整批效果仍由用户真实看图。

## 6. 发行边界

公开地址预定为 `https://github.com/wukongai/ip-pic-skill`。在用户另行确认前，不 push、不 tag、不发布 Release、不修改 Global Skill；因此外部安装测试必须等地址真实发布后执行。
