# IP 配图自然语言选择门

这份协议只约束用户对话层；它不替代 Image-factory director 的镜头、动作、表情和隐喻规划。

## 何时必须询问

用户只说“给我配图 / 生图 / 按这篇文章配图”，但没有一次性明确参数时，必须先发出选择提醒，不能直接编译：

```text
我可以按当前场景的推荐模式直接继续，也可以先让你选择交付方式、尺寸、IP 风格和标题样式。
你要沿用推荐，还是展开自选？
```

用户确认“沿用推荐”后，写入这个个人推荐预设：`ip_article_illustration + direct-integrated + 16:9 + minimal-lineart`，即“正文 IP 配图 + 一次生成少量短字 + 16:9 + 简约线稿”。用户选择“展开自选”后，再按独立维度询问：

确认后必须写入一个 `selection_receipt`，至少包含 `status: confirmed` 和 `source: user-explicit` 或 `user-accepted-recommendation`。这不是用户需要理解的命令参数，而是上游交给 IP Pic 的“已确认”凭证；没有它，不得编译 prompt、创建 render handoff 或调用图片 API。

1. 业务类型：正文配图或视频关键帧。通常可从用户请求直接识别，不要让风格反向改变业务类型。
2. 文字策略：
   - `direct-integrated`：一次生成图文融合成品；适合希望 IP、物件和少量短字在同一画面里表达。
   - `two-step-publish`：一次任务内部先生成无字原图，再自动扩展画布并合成标题带；用户只收到最终图。
3. 画布：`16:9`、`1:1`、`3:4`、`9:16` 或自定义宽高。画幅是独立参数，不由毛毡、拼贴等风格偷偷决定。若选 `two-step-publish`，要分别确认 raw 原图画布和最终发布画布（例如 `1:1` 原图 → `3:4` 发布图）。
4. IP 渲染风格：简约线稿、毛毡手作、贴画拼贴、松弛手绘、高冲击、艺术版画。它只改变材质和视觉语言。
5. 只有 `two-step-publish` 才询问标题带 extension；`editorial-ink-v2`
   是原版粗体墨线层级，`editorial-warm-v1` 是兼容暖纸层级。确认值写入
   `selection_receipt.publish_extension_id`，不能把一次生成的短字风格与
   二次标题带混为一层。

如果用户已经在自然语言中明确了某个参数，就记录它并跳过该项询问；不能再次用默认值覆盖。“沿用推荐”是一次明确确认，不是静默默认。用户未确认推荐或自选结果前不得编译。

## 用户可见的风格菜单

六风格对照组固定为同级选项：

| 用户说法 | `style_variant_id` | 只改变 |
|---|---|---|
| 简约稿 / 极简线稿 | `minimal-lineart` | 黑线、白底、克制强调色 |
| 毛毡 / 手作 / 丑萌 | `playful-craft` | 毛毡材质、缝线、手作形状 |
| 贴画 / 拼贴 | `sticker-collage` | 撕纸、贴画、网点、错位套色 |
| 松弛手绘 | `expressive-handdrawn` | 墨线、马克笔、蜡笔痕迹 |
| 特别吸睛 / 高冲击 | `pop-impact` | 撞色、粗轮廓、视觉爆点 |
| 艺术 / 版画 | `art-print` | 木刻、单版画、水粉色域 |

自然语言入口不得再把风格直接解析为 `*-video-square-*` 模板。先按业务类型选结构基底，再叠加 render style profile。比如“16:9、带短字、毛毡”必须保持 `ip_article_illustration + direct-integrated + 16:9`，只把 `style_variant_id` 改为 `playful-craft`。

## 推荐话术

```text
我建议沿用你的个人默认：正文 IP 配图、一次生成少量短字、16:9、简约线稿。
请确认或修改：
1) 文字策略：一次短字融合，还是无字图后二次标题？
2) 画布比例：16:9 / 1:1 / 3:4 / 9:16 / 自定义？
3) IP 风格：简约线稿 / 毛毡手作 / 贴画拼贴 / 松弛手绘 / 高冲击 / 艺术版画？
4) 若选二次标题，再选发布画布和标题带样式。
```

如果用户只回复“配图”“可以”“按默认”，而上下文没有形成可复述的推荐值，仍要先复述推荐值并请求一次确认，不能把模板 JSON 的 `default_for_scene` 当作确认。

“旧模板”“原来的风格”“先做前两张”只表示风格线索或数量范围，不代表用户已经选择交付模式、画布和最终交付物；仍必须触发上面的提醒。

direct-integrated 对中文长标题的字形稳定性较弱；用户要求准确、醒目的标题时，可推荐 `two-step-publish`，但仍需用户确认交付模式。
