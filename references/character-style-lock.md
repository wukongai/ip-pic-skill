# 人物与画面质感锁定

已授权角色 IP 的人物和画面质感只来自本次运行明确选中的：

- `visual.ip_profile`；
- `visual.authorized_assets` 中被 reference plan 选中的素材；
- profile 内声明的 `identity`、`appearance`、`personality` 与 `continuity_anchors`。

不得假设、搜索或引用未随公开 Skill 提供的角色资料。用户未提供角色或授权依据时停止。字体、标题和字幕属于独立版式层，不得从角色参考图反推为固定模板。

## CARTOON-IDENTITY-001 · 卡通优先的身份锁定

- 主参考必须是用户授权并在本次输入中声明的角色素材；未列入 reference plan 的图片不能作为隐式参考。
- 面部、发型、服装、配色、配件和体态只遵循 profile 中实际存在的连续性锚点，不补写任何私人外貌事实。
- 人物、手、服装和物件共享同一线稿精度、明暗语言与渲染风格，禁止照片素材与卡通装置拼贴。
- 已被用户否决为偏写实、3D、人物漂移或角色错配的输出，不得进入下一批参考集合。
- 参考素材只用于当前获授权角色，不得迁移其身份特征到另一角色。

任何新图命中以下任一情况，人物/质感 QA 直接失败：

- 角色身份、服装、配色或 profile 声明的连续性锚点明显漂移；
- 擅自增加、删除或改变 profile 声明的配件；
- 画面材质偏离所选渲染风格，或人物与装置像两张素材拼贴；
- 输出变成未请求的照片、3D、儿童卡通或企业矢量吉祥物；
- 使用了 reference plan 之外的角色素材；
- 角色可辨认，但表面语言与已选二维编辑插画风格不一致。
