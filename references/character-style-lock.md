# 人物与画面质感锁定

已授权角色 IP 的人物和画面质感事实源是：

- `profile://selected-character`
- `../assets/approved-v2/reference-set.json`
- `../assets/approved-v2/character-style-bible.md`

生成或评审时先检查人物与质感，再检查内容构图。字体、标题和字幕仍属于未锁定的独立版式层，不得从参考图反推为固定模板。

## CARTOON-IDENTITY-001 · 卡通优先的身份锁定

- 人物主参考必须是已确认角色三视图与 `approved-v2`；真人照片只允许校验身份神韵，不得作为材质、光影或皮肤渲染参考。
- 面部使用清晰墨线、概括色块和 2–3 级赛璐璐明暗；眼睛可轻微插画化，但年龄、脸型、眼镜和所选角色 profile 的连续性锚点必须保持本人辨识度。
- 皮肤均匀干净，但不能出现毛孔、摄影柔光、照片级渐变、真人毛发丝或网红磨皮。
- 人物、手、服装和物件必须共享同一线稿精度与明暗语言，禁止“真人抠图 + 卡通装置”。
- 已被用户否决为偏写实、网红脸、3D 或人物漂移的输出，不得进入下一批参考图集合。

任何新图命中以下任一情况，人物/质感 QA 直接失败：

- 脸部滑向真人照片、半写实网红脸或明显换人；
- 腰粗、短腿、大头或小直筒裤；
- 默认所选角色 profile 的连续性锚点被替换成普通通勤裤；
- 厚底所选角色 profile 的连续性锚点变成薄底普通运动鞋；
- 戒指不在左手食指，或所选角色 profile 的连续性锚点消失；
- 背景不再是清爽纯白；
- 人物与装置像两张素材拼贴，线条、光影或精度不一致；
- 画面变成照片、3D 渲染、儿童卡通或企业矢量吉祥物。
- 角色虽然能认出本人，但表面仍像照片或半写实数字人，而不是明确的二维编辑卡通。
