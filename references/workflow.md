# Content Direction Workflow

## 七步内核

1. 从内容中选认知锚点，不按字数平均切段。
2. 每张图只解释一个判断、状态或转折。
3. 先选结构：单一隐喻、前后对比、短流程、分层方法、路线转折或小型因果系统。
4. 把抽象概念改写成具体物理动作，再选择一到两个低科技物件。
5. 让角色执行必要动作；去掉角色后隐喻若仍完整，说明角色只是装饰，需要重构。
6. 在连续图片中轮换尺度、位置、朝向、动作和表情。
7. 每张独立编译和生成，逐张 QA；只修失败层，不把提示词无限叠加。

## 角色表演

按顺序确定：

1. 内容语义决定态度：平静解释、专注操作、怀疑核验、恍然发现、担忧提醒或笃定收束。
2. 动作对象决定视线。
3. 物理关系决定头部和身体姿态。
4. 风格只决定线条、材质和色彩，不改变身份和态度。

默认表情克制。强调转折时可以增强，但不能持续整批夸张。

## 三画幅

- 16:9：横向因果关系和文章正文阅读，保留较大呼吸空间。
- 1:1：缩略图可读的中心张力，边缘均需安全空间。
- 9:16：上部内容动作、中下部确定性文字区、底部和右侧平台安全区。

三种画幅各自重新构图，不共享裁切坐标。
