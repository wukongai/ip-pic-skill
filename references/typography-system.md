# 已授权角色 IP 中文文字系统

本系统只管理静态观点文字。逐字口播字幕属于 下游视频工具，不得烘焙进静态配图；测试图最多标记字幕安全区。

## IP-TYPE-001 · IP 主题卡式三级文字层级

**失败模式**：主标题、小栏目和补充内容字重、颜色、字体气质趋同；蓝字过深、过细或过度艺术化；红线重复出现，导致画面死板或像模板海报。

**严重度**：QA FAIL。文字层级是内容理解入口，错误会让静态观点与视频字幕互相争抢。

### 一级：核心观点

- 一张图只保留 1 句核心判断，建议 8–18 个汉字，最多 3 行。
- 使用大号、厚重、清晰的黑色中文展示字体；允许现代黑体或具有稳重粗细对比的编辑型宋黑混合风格。
- 字块靠左或随人物位置镜像，不固定塞进白色卡片。
- 默认不把主标题中的词改成蓝色；标题主体以黑色建立稳定重心。

### 二级：红色强调

- 全图最多使用 1 组红色强调，默认是一条位于核心观点下方的不规则手绘线。
- 红线长度约为主标题字块宽度的 55%–82%，不能每一行都加线。
- 同一画面不得同时使用“整词红字 + 多条红线 + 红色框”三种强调。
- 没有明确语义重点时，保留黑字与单条红线即可。

### 三级：蓝色信息

- 栏目名／kicker：使用正式、端正、中等偏粗的蓝色字体，不用手写体、儿童体或装饰体；推荐说明蓝 `#4B79A6`。
- 补充判断／关键词：字号小于栏目名，字重为 medium 或 semibold，禁止细体；推荐较浅说明蓝 `#6E93B7`。
- 栏目名与补充内容必须至少在字号、明度、字距三项中有两项不同，不能像同一级列表。
- 蓝色只承担导航和补充证据，不与黑色主标题争夺第一视觉层级。

## 数据镜头：data evidence

- 只有原文存在真实数字、比例、数量、排行或明确前后变化时使用。
- 最多一个主数字和两个辅助事实；数字要大，解释要短。
- 数据模块进入主题装置附近，不能统一堆在底部小字框。
- 没有数字时可以表达“变量—变化—结果”，但不要伪装成统计数据。

## 字幕边界

- 静态图片只承载长期成立的观点、关键词或真实数据。
- 逐字字幕由 下游视频工具 动态叠加；图片生成阶段只保留低细节安全区。
- 预览需要展示字幕位置时，使用单独的调试层，交付 PNG 默认不含模拟字幕。

## Remediation

若 QA 失败，保持 raw 人物和场景不变，只重做确定性文字层：先恢复黑色核心观点，再保留一条红线，最后分别设置两级蓝字；不得为修字体重新生成整张人物图。

## 禁止

- 每张图片都套同一底部证据卡；
- 细小的三行说明文字；
- 蓝色栏目名和蓝色补充内容使用相同字号、字重与颜色；
- 蓝字使用过深近黑色、过细字重或夸张艺术手写体；
- 每行标题都加红色下划线；
- 用彩色项目符号替代真正的信息层级；
- 生图模型直接生成最终中文；
- 为填满留白而增加无来源的标签或数字。
