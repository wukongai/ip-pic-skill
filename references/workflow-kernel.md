# 上游工作流内核

本文件定义从 Ian Xiaohei Illustrations 继承的“方法”，不定义最终画风。

## 保留的七步内核

1. 从长文中选认知锚点，而不是平均切字数。
2. 为每个锚点建立独立镜头条目，一张只解释一个判断。
3. 先选结构类型，再发明具体的物理隐喻。
4. 让固定角色执行必要动作，角色不是贴纸。
5. 用镜头清单约束尺度、朝向、位置和动作轮换。
6. 每张独立生成，避免上一张构图污染下一张。
7. 逐张 QA，不合格时只修失败层，不整套提示词越堆越长。

## 不由内核决定的内容

- 人物应该大还是小；
- 是极简线稿、编辑插画还是半写实卡通；
- 标题字号、字体、红线、数据模块位置；
- 16:9 或 9:16；
- 角色的脸、服装、饰品和品牌色。

这些由 `profiles/`、`layout-recipes.md`、`typography-system.md` 和具体模板决定。不得再从“继承工作流”推导出“必须小人物、必须大量留白、必须未授权第三方角色式批注”。
