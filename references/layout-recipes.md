# 已授权角色 IP 多画幅镜头版式

同一条口播需要轮换版式；16:9、1:1 与 9:16 必须分别设计，禁止先生成一个画幅再机械裁切。

## 三种画幅

### 16:9 横屏 · 独立字幕行

- 推荐结构：左侧 28%–34% 静态观点，中部 32%–40% 主题装置，右侧 26%–34% 人物动作。
- 底部约 17% 为连续低细节字幕行；人物脸、手部动作、标题和关键装置必须位于字幕行上方。
- 横向阅读顺序应是“观点 → 关系／装置 → 人物动作”，不能像竖图被左右截断。

### 1:1 方屏 · 浮动字幕

- 这是当前 连续内容短视频默认画幅。画布为 1:1，但内部优先使用横向 4:3 的叙事关系组织标题、主题装置和人物动作，不把竖版硬裁成方图。
- 不固定“左上观点 + 中左装置 + 右侧人物”。从 `diagonal-cross / top-down-partial / seated-loop / close-hands / object-dominant / contrast-bridge` 六种家族轮换。
- 底部约 15% 保持低细节，供 下游视频工具 浮动字幕覆盖；静态图不绘制字幕框。
- 人物和装置视觉质量接近，不使用“右侧巨型人物 + 左侧微型系统”。
- 标题可位于左上、右上、左中或下部安全区上方，但必须与隐喻形成一个视觉组；不允许标题漂浮在与画面无关的空白角落。

### 9:16 竖屏 · 浮动字幕

- 推荐结构：上部或左上静态观点，中部主题装置，中右或下右人物动作。
- 下部约 16% 保持低细节，最右约 10% 避让平台交互控件。
- 人物默认使用 `co-lead` 或 `analysis-medium`，品牌开场才使用 `brand-hero`。

## 七类镜头菜谱

| recipe | 人物尺度 | 适合内容 | 推荐动作 |
|---|---:|---|---|
| `editorial-hero` | 38%–52% | 开场、核心判断、段落结论 | 站立操作、半转身、手持关键物件 |
| `concept-partner` | 32%–46% | 概念、机制、产品能力 | 推、接、拆、称、连接、调节 |
| `data-evidence` | 28%–42% | 有真实数字、排行、增减、对比 | 核对、标记、拨表盘、观察 |
| `contrast-split` | 30%–44% | 前后对比、旧新方案 | 跨越、拉开、切换、回头确认 |
| `workflow-stage` | 26%–40% | 过程、步骤、系统流转 | 搬运、筛选、装配、回收 |
| `seated-analysis` | 34%–48% | 解释、复盘、冷静判断 | 坐姿记录、电脑操作、桌边思考 |
| `close-up-detail` | 36%–55% | 强调表情、饰品、科技极客感 | 半身侧看、手部操作、近景确认 |

## 轮换规则

- 相邻镜头不得重复 `recipe + orientation + action`。
- 连续三张不得都是全身站姿；每 4–6 张至少有一次坐姿或近景。
- 正面、向右、向左、半转身交替；人物左右位置交替。
- `editorial-hero` 不得连续使用超过两张。
- 人物较大不等于内容退化：道具、关系或数据模块必须与人物动作形成一个共同主体。
- 三种画幅只共享认知锚点、人物身份和视觉风格，不共享物件坐标或裁切框。
- 1:1 批量镜头必须记录 `composition_family`；相邻镜头不得重复，最近六张至少使用四种家族。
