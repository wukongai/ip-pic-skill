# 用户自有 IP 的角色职责与动作

派生自上游 `xiaohei-ip.md` 的“角色参与核心动作”机制；角色外形、品牌权重和动作尺度由已授权角色 profile 重新定义。

## 角色定位

已授权角色 IP 是认真参与系统运转的知识工作者，也是稳定的品牌视觉锚点。人物可以较大，但不能成为与内容无关的主持人立牌或重复摆拍。

角色可以：

- 操作怪机器、秤、转盘、闸门或工作台；
- 搬运、连接、筛选、修补、拆解或记录内容；
- 坐在系统内部观察、标记、复盘；
- 只出现半身、侧身、背影、局部手部或坐姿；
- 在地图、路径或分层结构里作为比例较小的行动者。

角色不必每张完整出现。为了让主题成为内容主体，允许只出现背侧身、肩部、侧脸、双手、腿部动作或坐姿局部；但可见部位仍必须保持所选角色 profile 的连续性锚点、眼镜、服装与饰品锚点。

## 四种尺度

1. `brand-hero`：全身或大半身，约占画面高度 42%–52%，用于开场、核心判断和段落结论。
2. `co-lead`：全身、半身或坐姿，约占 34%–46%，人物与主题共同完成动作。
3. `analysis-medium`：约占 26%–40%，用于流程、数据和多对象关系。
4. `close-up`：半身、侧脸或手部近景，约占 36%–55%，用于表情、科技操作和节奏变化。

不得把 `brand-hero` 理解为“永远正面站立拿平板”；人物较大时更需要通过动作、侧向、坐姿和道具关系表达内容。

## IP-SCALE-001 · 人物与主题装置的可信尺度

**失败模式**：人物像巨人，主题装置、入口或人群像小人国；或反过来人物缩成角落贴纸，品牌识别消失。

**严重度**：QA FAIL。尺度失真会破坏人物与内容共同解释的可信关系。

- 默认优先使用 `co-lead`：人物高度约 34%–44%，主题装置高度或主视觉面积约 36%–48%。
- 人物与装置的主视觉面积比建议保持在 `0.75–1.35`；需要品牌开场时可放宽，但必须仍像处于同一物理空间。
- 人物的手、工具和装置操作面必须符合成人尺度，不能出现“手掌大于入口”“人物高于整座系统数倍”等关系。
- 表达用户群体时，优先使用同尺度的入口、票据、路径、砝码或抽象人形标记；禁止用写实微型人群与正常尺度人物同框制造小人国。
- 若内容必须出现人物群体，群体只能作为远景信息符号，不得与已授权角色发生需要真实尺度的直接物理互动。
- 画面需要更多留白时，缩减节点和装置数量，不机械放大人物填满空间。

**Remediation**：先删除微型人群和多余节点，再把人物与主装置重设为接近的视觉质量；不得只缩小人物或只放大机器掩盖问题。

## 动作池

- 拉、扛、塞、捞、压、称、缝、剪、拧、守、推、接、拆、标记、回收；
- 搭桥、扶梯、开门、调阀、拨表盘、整理抽屉、接水管、修轨道；
- 坐着观察、蹲下修补、俯身记录、侧身搬运、回头确认、伸手接住。

动作必须服务内容，不为姿势变化而摆拍。

## 连续镜头轮换

- 相邻镜头不重复同一 `scale + orientation + action`。
- 连续三张不得都站立；连续三张不得都正面；连续三张不得都使用平板。
- 每 4–6 张至少出现一次坐姿、局部动作或明显不同的身体重心。
- 正面、向左、向右、背身/半转身交替，人物位置左右轮换以平衡剪辑运动。
- 每 6 张至少覆盖：一次俯视局部、一次背侧身、一次坐姿、一次双手近景、一次跨画面对角动作、一次装置主导镜头。
- 相邻两张不得同时使用“人物居右 + 全身站立 + 双手摆放物件”；同一动作词在最近四张内最多出现一次。
- 人物动作应有身体重心：俯身、转身、蹲下、跨步、坐稳、伸手连接或双手整理；禁止只有手臂换方向、身体仍像主持人立牌。

## 判断标准

- 去掉人物后，主题仍可辨认，但品牌锚点和关键动作缺少执行者：人物参与度合格。
- 去掉人物后，画面完全不受影响：人物只是装饰，需要重写动作。
- 去掉内容装置后只剩一张漂亮人物海报：主题表达失败；优先重写人物与道具的关系，不机械地把人物缩小。
