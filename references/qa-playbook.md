# QA Playbook

把 QA 分成三层，不要用文件尺寸通过冒充视觉正确。

## 自动技术 QA

- 文件存在且可读取。
- 宽高比匹配目标画幅。
- render request 与实际输出一一对应。
- 没有输出到 Skill 根目录。
- prompt 和 manifest 先于图片存在。

## Agent 视觉 QA

- 角色仍像同一个角色，连续性锚点没有漂移。
- 角色推动核心因果动作，不是贴纸或主持人立牌。
- 一张图只表达一个核心判断。
- 物理隐喻来自当前内容，不复刻参考构图。
- 16:9、1:1、9:16 都是独立构图。
- 画面没有错误文字、假界面、代码、logo、水印或不可用安全区。
- 参考图只影响获授权的身份、外观或风格，不泄漏到最终交付说明。

## 用户确认

用户最终确认角色神韵、品牌适配和内容判断。Agent 应逐张列出通过、失败和待确认项；部分失败不能报告为整批完成。
