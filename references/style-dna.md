# 已授权角色 IP 编辑插画风格 DNA

上游 `style-dna.md` 只提供“单图单意、克制、少量强调色”的方法参考。人物尺度、成熟卡通质感和中文字体系由已授权角色本地 profile 独立定义。

## 一句话

干净白底、明确二维卡通、所选角色 profile 的连续性锚点、精致具象隐喻、克制配色、少量文字；人物与主题共同构成品牌画面。

## 必须

- 一张图只讲一个核心动作、结构、状态或隐喻。
- 纯白背景；允许物件内部有轻微手绘材质和落地阴影，但背景不使用纸纹、米色摄影棚、空间渐变或复杂场景。
- 人物必须一眼看出是二维编辑卡通：清晰轮廓线、概括面部、平涂与 2–3 级赛璐璐明暗；比未授权第三方角色样式更完整精致，但不做商业矢量吉祥物。
- 人物与主题装置形成一个共同主体，周围保留足够呼吸感。
- 人物必须有品牌存在感；主题必须有信息作用，不能缩成人物身边的装饰图标。
- `two-step-publish` 与视频关键帧的最终中文由确定性后处理叠加；`direct-integrated` 则由模型一次生成少量融合中文。两者都以一句粗黑主张和单条手绘强调线为视觉目标。
- 红色只用于标题强调；橙色用于人物动作与主路径；蓝色用于反馈、状态或第二层说明。橙色动线每张只保留一条主路径，避免箭头满屏。

## 画幅差异

### 16:9 正文图

- 概念主体约占画面 40%–60%。
- 人物通常占画面 10%–25%，可以是全身小角色、半身操作员或局部动作。
- 不使用封面级大标题。

### 9:16 视频关键帧

- 上部约 5%–67% 是内容场景，中下部为观点与证据信息，底部约 10% 和右侧避让平台 UI。
- 概念主体约占画面 45%–65%。
- 人物默认占画面高度 38%–52%；流程或数据镜头可降至 26%–42%，近景可到 55%。
- 人物不能连续多张采用同一版式、尺度、朝向和站立指向动作。
- 标题位置跟随人物和主题动态调整，不固定使用底部证据卡。

## 绝对不要

- 人物变成无内容的人像海报，或主题退化成身旁小道具。
- 人物缩成角落贴纸或小操作员，只剩说明书式装置图。
- 连续站立、指向、拿平板的个人海报。
- PPT 信息图、正式流程图、课程课件、复杂架构图。
- 可爱吉祥物、儿童卡通、精致扁平商业插画。
- 真实 App 截图、科技 UI、密集文字墙。
- 泛化的工厂、锅炉、管线、传送带、密集齿轮或蒸汽朋克装置；AI 主题不得默认翻译成工业时代机器。
- 漂浮玻璃面板、软件仪表盘和模块卡片堆叠；具象隐喻不得退化成 PPT 或产品 UI。
- 把结构类型名称写到图上。

高质量画面应该同时让人认出“这是已授权角色的内容”，并一眼理解当前主题；两者不互相牺牲。
