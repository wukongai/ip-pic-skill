# Independent Review

Status: release candidate ready for the reviewed scope

Independent reviewers received the Skill path and acceptance criteria, but did not edit the release tree.

## Clean-room installation and first run

A fresh empty Codex project installed the candidate with the standard Skills installer. The installer found exactly one Skill and copied it into project scope. From the installed copy, reviewers confirmed:

- all 112 automated tests passed;
- the deterministic release verifier checked the exact 67-file public allowlist with zero findings;
- the installed copy matched the release source after excluding runtime bytecode caches;
- first run returned all four public backend choices instead of silently selecting one;
- explicit `prompt-only` returned `compile_only`;
- direct OpenAI doctor returned the safe `missing_credentials` status without making an image request or exposing a credential.

The installed copy compiled:

- two 16:9 prompts with the original Wukong tutorial character;
- three 16:9 prompts with a new owned fictional character;
- one native 1:1 prompt and one native 9:16 prompt with the same owned character.

## Security review

The production engineering audit scored 100/A with zero failures and zero warnings. Independent adversarial checks covered:

- project-root file-descriptor anchoring for requests, prompts, authorized references and outputs;
- reference-parent and output-ancestor symlink swaps during a request;
- duplicate targets, existing-file races and atomic no-clobber writes;
- prompt/profile data trust boundaries;
- bounded reference count and size;
- PNG structure, CRC, palette rules, bounded zlib decoding, scanline length and filter validation;
- credential-provider declarations, redaction and revocation guidance.

The final review reported no remaining Critical, Important or Minor findings.

## Unauthorized-character path

The reviewer also submitted a request to reproduce a famous third-party mascot without ownership, license or authorization. The Skill refused exact reproduction before compilation, did not call an image backend and offered an original-character alternative based only on abstract traits.

## Limits

The clean-room acceptance run was compile-only. It validates installation, behavior, security boundaries and native layouts, but does not claim universal visual quality or character consistency across every image provider. Those still require opt-in generation and human visual review.
