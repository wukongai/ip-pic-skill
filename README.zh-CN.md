# ip-pic · IP 配图

[简体中文](README.zh-CN.md) | [English](README.en.md)

`ip-pic` 是一个面向内容创作者的 Agent Skill。它使用固定原创或已授权角色，为中文文章制作单张配图、连续多图和静态视频关键帧。

把它交给 Codex、Claude Code、WorkBuddy 等 Agent，就可以开始给文章配图。

## 30 秒开始

把下面这句话发给 Agent：

```text
帮我安装并使用这个配图工具：
https://github.com/wukongai/ip-pic-skill
安装完成后，带我完成第一次配图。
```

安装后，你可以直接说：

```text
用学习向导阿拓给下面这段文字配 1 张图。
```

```text
用我的角色给这篇文章配图。
```

```text
读取我当前的 Obsidian 文章，自动选择值得配图的位置。
```

完整的首次参考图、短文、长文、自己的角色、风格、画幅、字体和失败重做流程见：

- [普通用户手册](USER-GUIDE.zh-CN.md)

## 出图方式

默认推荐 GPT Image 2，共有三种真实出图方式：

- 使用 Codex 时，直接调用内置 Codex Image Tool / `$imagegen`，不需要配置 API Key；
- 没有 Codex 时，由 Agent 接入 OpenAI 官方 API，或接入宿主已有的图片中转站；
- 已经有 ai-router 时，使用宿主的 `ai_router.generate_image`。

官方 API 的 `OPENAI_API_KEY` 放在宿主安全凭证存储或运行环境中；中转站的地址、Key 和模型放在宿主工具或 ai-router 的用户级配置中。它们都不能写进 IP Pic 或文章项目。`prompt-only` 只准备提示词，不会生成图片。

每一种方式可以直接复制给 Agent 的话，以及“配置到底放在哪里”，都在[普通用户手册的第二步](USER-GUIDE.zh-CN.md#第二步选择真实出图方式)。

## 用户可以选择什么

文章风格：

- 简约线稿
- 毛毡手作
- 贴画拼贴
- 松弛手绘
- 高冲击
- 艺术版画

常用自然语言：

```text
改成毛毡手作和 1:1，生成新版本，不覆盖旧图。
```

```text
改成先无字图再加标题，使用原版较粗中文字和单条手绘强调线。
```

```text
保留已经通过的图片，只重做失败项。
```

## 能做什么

- 16:9、1:1、3:4、9:16 与自定义画布；
- 一次生成图文融合，或先做无字图再稳定加入中文标题；
- 原版较粗中文字、两级蓝字和单条手绘强调线；
- 文章短文单图与长文连续多图；
- 方屏、横屏和竖屏静态视频关键帧；
- 同一角色连续出图、失败重做和逐图确认。

一次生成图文融合时，主标题沿用原版较粗、端正的黑色中文展示字，标题下只画单条不规则手绘强调线。

## 能力边界

IP Pic 不用于：

- 知识卡片、封面或海报；
- Obsidian 管理、文章写作或内容发布；
- 动画、口型、配音或视频剪辑；
- 未授权第三方角色的精确复刻。

Agent 可以读取用户交给它的 Obsidian Markdown 文章，再把内容交给 IP Pic；IP Pic 本身不会接管或修改用户的笔记系统。

## 安全与许可

- 用户角色和参考图必须为本人拥有或已获授权。
- 用户参考图保存在自己的写作项目中。
- 被否决图片不会自动成为后续参考图。
- 自动检查不能替代用户本人看图。
