# ip-pic · IP 配图

[简体中文](README.zh-CN.md) | [English](README.en.md)

`ip-pic` 是一个面向内容创作者的 Agent Skill。它使用固定原创或已授权角色，为中文文章制作单张配图、连续多图和静态视频关键帧。

普通用户不需要运行命令、寻找 Skill 目录或编辑配置。把公开地址和文章交给 Codex、Claude Code、WorkBuddy 等 Agent 即可。

## 30 秒开始

公开安装地址：

```text
https://github.com/wukongai/ip-pic-skill
```

把下面整段话发给 Agent：

```text
请在我当前的写作项目中安装这个 Agent Skill：
https://github.com/wukongai/ip-pic-skill

安装名称保持为 ip-pic，优先安装到当前项目，不要修改全局 Skill。
请你自己完成安装、依赖检查和自检，不要让我运行命令或寻找 Skill 路径。
安装完成后，请使用 ip-pic，检查安装并带我完成第一次使用。
```

安装后，你可以直接说：

```text
用学习向导阿拓给下面这段文字配 1 张图。
```

```text
用我的角色给这篇文章配图。
```

```text
读取我当前的 Obsidian 文章，自动选择值得配图的位置。
```

完整的安装、首次参考图、短文、长文、自己的角色、风格、画幅、字体和失败重做流程见：

## 用户可以选择什么

文章风格：

- 简约线稿
- 毛毡手作
- 贴画拼贴
- 松弛手绘
- 高冲击
- 艺术版画

常用自然语言：

```text
改成毛毡手作和 1:1，生成新版本，不覆盖旧图。
```

```text
改成先无字图再加标题，使用原版较粗中文字和单条手绘强调线。
```

```text
保留已经通过的图片，只重做失败项。
```

## 完整能力

- 13 个正式 IP 配图结构和 1 个兼容结构；
- 16:9、1:1、3:4、9:16 与自定义画布；
- 一次生成图文融合；
- 无字底图后确定性合成中文标题；
- 原版较粗中文字、两级蓝字和单条手绘强调线；
- 人物尺度、裁切、动作、表情、视线、姿态和朝向导演；
- 文章短文单图与长文连续多图；
- 方屏、横屏和竖屏静态视频关键帧；
- 授权参考图选择、批量连续性、失败重做和逐图检查；
- Agent 内置图片工具、用户 OpenAI 图片能力、已安装图片路由或只准备提示词。

一次生成图文融合时，主标题沿用原版较粗、端正的黑色中文展示字，标题下只画单条不规则手绘强调线。该模式由图片模型一次完成，不切换为 `two-step-publish`，也不做二次文字叠加。

## 能力边界

IP Pic 不用于：

- 知识卡片、封面或海报；
- Obsidian 管理、文章写作或内容发布；
- 动画、口型、配音或视频剪辑；
- 未授权第三方角色的精确复刻。

Agent 可以读取用户交给它的 Obsidian Markdown 文章，再把内容交给 IP Pic；IP Pic 本身不会接管或修改用户的笔记系统。

## 安全与许可

- 用户角色和参考图必须为本人拥有或已获授权。
- 凭证、token、cookie、私钥和私有图片路由实现不会进入公开 Skill。
- 用户参考图保存在用户项目中，不写回 Skill 安装目录。
- 被否决图片不会自动成为后续参考图。
- 自动检查不能替代用户本人看图。
