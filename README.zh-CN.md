# ip-pic · IP 配图

[简体中文](README.zh-CN.md) | [English](README.en.md)

`ip-pic` 是一个面向内容创作者的 Agent Skill。它使用固定原创或已授权角色，为中文文章制作单张配图、连续多图和静态视频关键帧。

把它交给 Codex、Claude Code、WorkBuddy 等 Agent，就可以开始给文章配图。

默认优先使用一次图文融合。给整篇文章配图时，Agent 会逐段分析，规划每张图的内容锚点、表情、动作和视线，并检查每张图与对应段落是否真正相关。

它也支持用自然语言保存和版本化你自己的角色、个人风格和导演预设。你可以让 Agent 记住常用参考图、表情、动作、视线和身体姿态；每次修改先看预览，确认后保存为新版本，随时可以切回旧版。私人配置只留在你的写作项目中。

## 30 秒开始

把下面这句话发给 Agent：

```text
帮我安装并使用这个配图工具：
https://github.com/wukongai/ip-pic-skill
安装完成后，带我完成第一次配图。
```

安装后，你可以直接说：

```text
使用 IP Pic 的学习向导阿拓示例，给下面这段文字配 1 张图：

真正让项目变快的，不是把计划写得更细，而是更早拿到可以检查的小结果。
```

首次使用时，Agent 可能先问图片保存到哪个项目，这是正常步骤；如果你还没有项目，它会给出简单选项。

```text
建立自己的角色后，用我的角色给这篇文章配图。
```

```text
读取我当前的 Obsidian 文章，自动选择值得配图的位置。
```

完整的文章配图、自建参考图、修改风格、新增个人风格、画幅、字体和失败重做流程见：

- [普通用户手册](USER-GUIDE.zh-CN.md)
- [验证说明](docs/VERIFICATION.zh-CN.md)

默认优先使用 GPT Image 2。正常使用时，Agent 会自动选择当前可用的图片工具；只有它明确说没有可用图片工具时，才需要查看[图片工具接入说明](IMAGE-TOOL-SETUP.zh-CN.md)。

## 用户可以选择什么

文章风格：

- 简约线稿
- 毛毡手作
- 贴画拼贴
- 松弛手绘
- 高冲击
- 艺术版画

常用自然语言：

```text
改成毛毡手作和 1:1，生成新版本，不覆盖旧图。
```

```text
改成先无字图再加标题，使用原版较粗中文字和单条手绘强调线。
```

```text
保留已经通过的图片，只重做失败项。
```

## 能做什么

- 16:9、1:1、3:4、9:16 与自定义画布；
- 一次生成图文融合，或先做无字图再稳定加入中文标题；
- 原版较粗中文字、两级蓝字和单条手绘强调线；
- 文章短文单图与长文连续多图；
- 方屏、横屏和竖屏静态视频关键帧；
- 同一角色连续出图、失败重做和逐图确认；
- 项目级角色、个人风格和导演预设的确认保存、不可变版本与回退。

一次生成图文融合时，主标题沿用原版较粗、端正的黑色中文展示字，标题下只画单条不规则手绘强调线。

## 能力边界

IP Pic 不用于：

- 知识卡片、封面或海报；
- Obsidian 管理、文章写作或内容发布；
- 动画、口型、配音或视频剪辑；
- 未授权第三方角色的精确复刻。

Agent 可以读取用户交给它的 Obsidian Markdown 文章，再把内容交给 IP Pic；IP Pic 本身不会接管或修改用户的笔记系统。

## 安全与许可

- 用户角色和参考图必须为本人拥有或已获授权。
- 用户参考图保存在自己的写作项目中。
- 被否决图片不会自动成为后续参考图。
- 自动检查不能替代用户本人看图。

## 独立发行说明

IP Pic 是从更大的工作流中独立拆分的公开 Skill，已完成自动化合同、安全、隐私与真实图片链路测试。不同 Agent、图片模型、字体和运行环境仍可能造成视觉差异；建议先运行阿拓示例，再用自己的文章和授权角色测试。发现可复现的问题时，请提交原文、运行环境和失败现象，但不要提交凭证或无权公开的素材。
